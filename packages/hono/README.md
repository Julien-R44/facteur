# @facteurjs/hono

Hono integration for Facteur - Send notifications via multiple channels in your Hono application.

## Installation

```bash
npm install @facteurjs/hono
```

## Features

- Lightweight integration for Hono
- Works on edge runtimes (Cloudflare Workers, Deno, Bun)
- Access to all `@facteurjs/core` channels
