# @facteurjs/react

React hooks and components for Facteur - Build notification centers in your React application.

## Installation

```bash
npm install @facteurjs/react @tanstack/react-query
```

## Features

- React hooks powered by TanStack Query
- Optimistic updates
- Real-time support
