# @facteurjs/client

JavaScript client for Facteur - Fetch and manage notifications from your frontend application.

## Installation

```bash
npm install @facteurjs/client
```

## Features

- Framework-agnostic client
- Fetch, mark as read, delete notifications
- TypeScript support

## Documentation

Full documentation available at [facteur.julr.dev](https://facteur.julr.dev)
